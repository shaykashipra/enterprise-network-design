# Topology Artifacts

Create these files manually after building the Packet Tracer lab:

- `enterprise_network.pkt`: save the completed Cisco Packet Tracer project here.
- `topology.png`: screenshot of the full Packet Tracer topology.
- `network_diagram.png`: clean diagram version of the topology, if you create one separately.

Screenshot checklist:

1. Full topology
2. `show vlan brief`
3. `show interfaces trunk`
4. `show ip interface brief`
5. `show ip route`
6. `show ip ospf neighbor`
7. Successful HQ-to-branch ping
8. ACL blocked HR-to-Finance ping
9. Simulation Mode packet flow
